# NOVA PDF & Image Tools

Privacy-focused PDF and image utilities that run locally in the browser. Built with Vite, native Canvas APIs, and lazy-loaded `pdf-lib` for PDF tasks.

## Development
`npm install` then `npm run dev`.

## Production
`npm run build` produces the deployable `dist/` directory. Deploy it to any static host with SPA route fallback to `index.html`. No backend or file upload endpoint is required.

## Implemented tools
PDF merge, split/extract, rotate, watermark, page numbering, metadata viewer, Images to PDF, plus image compress, resize, crop, convert, rotate, background replacement, and metadata viewer. Files are not persisted or sent to a server.
